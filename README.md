# React Diploma Project — интернет-магазин

Учебный frontend-проект, выполненный в рамках курса по React.  
Проект представляет собой интернет-магазин обуви с базовым пользовательским функционалом.

---

## 🚀 Функциональность

- главная страница с каталогом и хитами продаж
- фильтрация товаров по категориям
- поиск товаров
- страница товара с выбором размера и количества
- корзина с хранением данных в localStorage
- оформление заказа
- обработка загрузки и ошибок
- страница 404

---

## 🛠 Используемые технологии

- React
- Vite
- JavaScript (ES6+)
- Context API
- React Router
- localStorage

---

## 🔗 Взаимодействие с сервером

- получение списка товаров и категорий
- загрузка данных о товаре
- поиск и фильтрация
- оформление заказа

Backend предоставлялся в рамках задания и не редактировался.

---

## 📌 Что реализовано в рамках обучения

- разработка frontend-приложения на React
- работа с HTTP-запросами
- управление состоянием приложения
- маршрутизация
- обработка состояний загрузки и ошибок
- взаимодействие с готовым backend API

---

## 📚 Статус проекта

Проект выполнен в учебных целях.  
Основной фокус — практика frontend-разработки и понимание взаимодействия frontend и backend.
